Sanity & page-builder glossary

The canonical vocabulary. Every lesson uses these words exactly this way.

TermMeaningIn this repo
Content LakeSanity's hosted database. Stores documents as JSON. Nothing visual lives here.Project z5112m0c, dataset production
DocumentOne JSON record with an _id and _type. The unit of storage and publishing.page, product, testimonial, menu, siteSettings
SchemaCode that declares what fields each type has. Sanity stores anything; the schema tells the Studio what to offer editors.sanity/schemaTypes/ + blocks/*/schema.ts
StudioThe editing UI — a React app generated from your schema. It is a client of the Content Lake, not the database itself.Embedded at /studio (sanity.config.ts)
Object typeA structured value that lives inside a document (no own _id).Every block; linkField, specRow, metadata
BlockOur word for an object type allowed in page.content[] — one section of a landing page.21 of them: heroBlock … contactFormBlock
ReferenceA pointer from one document/object to a document ({_ref: "id"}). Enables reuse: edit once, updates everywhere.productListBlock.items[].product → product
GROQSanity's query language. Filters documents and projects (reshapes) them.sanity/lib/queries.ts
ProjectionThe {...} part of a GROQ query — chooses and renames fields, follows references with ->.productFragment, per-block projections
Portable TextRich text stored as a JSON array (not HTML), so it renders anywhere.richText fields → components/RichText.tsx
AssetAn uploaded image/file. Stored once, referenced by documents, served from Sanity's CDN with on-the-fly transforms.image{asset->{url}}, hero video file
DatasetA named bucket of documents inside a project (like a DB instance).production
DraftUnpublished version of a document (drafts. id prefix). Editors see it in draft mode; visitors don't.Presentation preview via /api/draft-mode/enable
RegistryOur map from block _type → React component.blocks/registry.tsx
Resolved shapeWhat a query returns after projection — not what is stored. Components and demo content use this shape.sanity.types.ts (PAGE_BY_SLUG_QUERY_RESULT)
Demo modeNo Sanity env vars → the site renders from hand-written content in the resolved shape.content/demo.ts via sanity/lib/loaders.ts
